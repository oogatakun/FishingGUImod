# 今後の追加機能(バックログ)

ユーザーが 2026-11-03 に書き起こしたアイデア。今すぐ実装するものではない。着手するときは、それぞれ brainstorm → 設計書 → 実装計画の順で進める。

## ユーザーの原文に沿った項目

1. 魚の種類と重さに応じて経験値も変わる。
2. レベルに応じて釣れる魚のレア度が高くなる。ただし、餌もそれに応じて良いものにしていかないと、良いものは釣れない。
3. 釣った魚を餌にできる。餌にした魚と同じ魚は 1% の確率でしか釣れない。
4. 同じレベル同士の魚(と餌)で釣りをしても、同じレベル**以下**の魚しか釣れない(2026-11-03 に「同じレベルのみ」から変更)。たまにひとつ上のレベルの魚が釣れる。
5. 釣った魚は焼いて食べられるようにする。魚ごとに回復度、満腹度、隠し満腹度(飽和度)が違う。重量は関係しない。
6. 川や海など、場所によって釣れる魚が変わる。エンチャントでどこでも釣れるようにできる。ランクはこのエンチャントに含まれない。

7. 釣果画面の選択肢に、キープ、リリースに加えて、第3の「リリースしてポイントに変換」を追加する。魚のレア度と重さによって、取得できるポイントが変わる。
8. そのポイントを使ってスキルを取得できるようにする。スキルの中身は後で決める。

## 既存のロードマップとの対応

- 項目 2、3、4 は Phase 3-C(レベルで変わる餌と釣れる魚)の中身にあたる。
- 項目 1 は Phase 3-B で入れた「魚ごとの固定 xp」の拡張(重量を反映)。
- 項目 5、6 とオリジナル魚は、3-C の後。魚のアイテムが増えてから設計する。
- 餌の入手手段(レシピやドロップ)も未着手。項目 3(魚を餌にする)がその一部になる。

## 着手前に決めること(設計時の論点)

- 項目 1: 経験値の式。例は `基本xp × 重量補正` とする案。ファイトの重さ補正(0.8〜1.3 倍)と同じ係数を使うか。
- 項目 2、4: 「魚のランク」と、既存のレア度(common〜epic)および釣りレベルとの関係。ランクは別の軸にするか。餌にも同じランクを持たせるか。
- 項目 3: 「同じ魚は 1%」の判定の単位(魚の種類ごとか、ランクごとか)。餌にした魚の種類をどう覚えるか(アイテムに NBT で持たせる案)。
- 項目 3: 魚を餌にしたときのバフ効果(現在の3種の餌との関係)。
- 項目 5: 魚ごとの回復度・満腹度・隠し満腹度を、データパック JSON で持つか。焼いた魚を別アイテムにするか。
- 項目 4: 「同じレベル以下」と、項目 2(レベルが上がるほどレア度が高くなる)との関係。レベル以下の魚の中の出やすさ(高いレベルの魚ほど出やすいか、均等か)。
- 項目 7: 「リリースしてポイントに変換」は、通常のリリースと同じく釣り経験値が入るか。ポイント式は `レア度係数 × 重量` などの案。
- 項目 8: ポイントの保存先(経験値と同じ永続データ)、スキルの取得画面、スキルのリセット可否。スキルの中身は後で決める。
- 項目 6: 「場所」はバイオームタグ(川、海、深海など)で判定する案。エンチャント名とレベル数。ランクを含まない、の意味(ランクの制限は場所に関係なく効く)。
