# Phase 5: 七輪と焼き魚 設計書

- 関連: `docs/superpowers/backlog.md` の項目 5
- 日付: 2026-11-05
- 対象外: ファーマーズディライト(FD)用のレシピ(別フェーズ。入っているときだけ有効にする方針だけ決めてある)、七輪以外の焼き方(かまど・焚き火・燻製器では焼けない)。

## 1. 焼き魚アイテム

- 56 種のオリジナル魚ごとに「焼いた○○」を別アイテムとして追加する(ID `cooked_<魚ID>`、例 `cooked_aji`)。スタック 64。
- バニラのタラ・サケは、バニラの焼いたタラ・焼いたサケにそのまま焼ける。熱帯魚・フグは焼けない(七輪に置けない)。
- 画像は共通の仮画像(`cooked_fish.png`)を全 56 種のモデルから共有する。あとでキットで差し替える。魚ごとの画像は今回作らない。
- 焦げた魚: 魚によらず 1 種類(`burnt_fish`)。画像はキットで作る(2D)。

## 2. 食べたときの効果(レベルから自動、重量は無関係)

| 項目 | 式 |
|---|---|
| 満腹度(食料ポイント) | `3 + floor(0.3 × (Lv-1))` (Lv1: 3、Lv10: 5、Lv20: 8) |
| 隠し満腹度(飽和度の係数) | `0.6 + 0.01 × (Lv-1)` (Lv20: 0.79) |
| 回復度(食べた直後の体力、半ハート) | common 0、uncommon 1、rare 2、epic 4 |

- 純 Java の `FoodRules`(`nutrition(level)`、`saturationModifier(level)`、`heal(rarity)`)にし、単体テストする。
- 魚ごとの個別調整: `fish_profiles` の JSON に任意の `"food": {"nutrition": n, "saturation": s, "heal": h}` を書くと上書きできる(書かなければ自動)。`FishProfileParser` と `FishInfo` に任意項目として足し、パーサーのテストを追加する。
- 回復度は、食べ終わったとき `Player.heal(h)` で与える(専用の `CookedFishItem`)。
- 生の魚は食べられない。焦げた魚: 満腹度 1、飽和度の係数 0.1、回復なし。
- 食べる速度はバニラの魚と同じ。

## 3. 七輪(ブロック)

- ID `shichirin`。クラフト: レンガ 5 個を U 字に + 中央に鉄インゴット 1 個(木炭・石炭の入れ物になる焼き物の器)。壊すと自分自身を落とす(ツール不問)。
- 見た目: キットの 3D ルートで作る(幅 12×12×高さ 10 の低い器、上は網)。点火中は上面が赤く光る(ブロック状態 `lit`)。
- ブロックエンティティが次を持つ: 燃料の残り tick、置いた魚(最大 2 つ)、それぞれの焼け具合(tick)。
- **操作(右クリック)**:
  - 木炭・石炭を持って右クリック → 燃料に 1 個足す(燃料 1 個で 1600 tick。最大 4 個分を貯められる)。
  - 焼ける魚を持って右クリック → 空いているスロットに 1 個置く(燃料が無くても置ける。点火中だけ焼ける)。
  - 素手で右クリック → 焼けた魚(または焦げた魚)があれば、それを取り出す。焼ける途中の魚は、取り出すと元の魚が戻る(ブレイクしても同じ)。
- **表示**: 置いた魚を、網の上に小さく表示する(ブロックエンティティレンダラー)。魚は焼けると焼き魚の見た目に変わる。
- **焼き時間**: `cookTicks(level) = 200 + 20 × (level - 1)`(Lv1: 10 秒、Lv20: 29 秒)。純 Java の `CookingRules` に置く。
- **焦げる**: 焼けたあと、取り出さないまま 400 tick(20 秒)点火し続けると、焼き魚が焦げた魚に変わる。燃料が尽きた場合は、そこで進行が止まる(焦げない)。
- **燃料が尽きる**: 燃料が 0 になったら消灯し、焼け具合の進行を止める(戻らない)。
- 水が当たる(雨を含まない、隣の水)ときや、水中での特別な処理はしない。
- サーバー側ですべて処理し、ブロックエンティティの同期でクライアントに送る。

## 4. データ

- 焼ける魚と結果の対応は、純 Java の `CookingRules` が `FishIds` から生成する(JSON のレシピは作らない)。バニラの 2 種は固定の表に持つ。
- 魚のレベルとレア度は既存の `FishLevels` と `FishProfileLoader` を使う。

## 5. 言語ファイル(ja / en)

`block.fishinggui.shichirin`(七輪 / Shichirin)、`item.fishinggui.cooked_<ID>` 56 件(「焼いた〇〇」/ "Grilled X")、`item.fishinggui.burnt_fish`(焦げた魚 / Burnt Fish)、七輪のツールチップ説明、「焼き魚の回復」ツールチップ(「体力 +N」)。名前は既存の魚の名前から生成する。

## 6. テスト

- `FoodRulesTest`(境界、回復度)、`CookingRulesTest`(焼き時間、焼けるかどうか、結果の対応、焦げる判定)、`FishProfileParserTest`(`food` の読み取りと省略時)。
- ブロックエンティティ・レンダラー・ゲーム内の操作は、ビルドと専用サーバーの起動で確認し、ゲーム内の確認はユーザーに依頼する。
- ビルド: `./gradlew compileJava test build`。

## 7. 実装の分割

1. 純 Java(`FoodRules`、`CookingRules`、パーサー拡張)とテスト。
2. 焼き魚と焦げた魚のアイテム(56+1 件の登録、モデル JSON、言語、クリエイティブタブ、ツールチップ)。
3. 七輪ブロックとブロックエンティティ、レンダラー、レシピ(クラフト)、画像(キットで作る)。
