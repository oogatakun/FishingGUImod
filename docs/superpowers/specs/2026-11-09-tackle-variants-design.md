# 釣り竿パーツの「型」追加 設計(計画のみ・未実装)

## 目的
既存の7パーツ(ロッド/リール/ライン/フック/フロート/リーダー/ルアー)に、釣りのスタイル別の「型」を足す。
既存パーツに素材を足して作り、同じランクの強さは変えず、性能の向きだけを変える。

## 決定事項(ユーザー確認済み)
- 増やし方: 今あるパーツを元に、いくつか素材を足して作る
- 性質: 得意/不得意の型(ランクの総合的な強さは同じ)
- 対象: 全7パーツ
- テクスチャ: ユーザーが渡す。無い型は今は作らず、標準型の絵で代用する

## 型の仕組み(2026-11-12 改訂: ユーザーのロッドセット絵に合わせる)
- 型 = 「釣りのスタイル」のセット。鉄・ダイヤ・ネザライトは各ランク2つ、木は3つ。現行の標準型(今あるパーツ)は、そのまま残す
- ユーザーの絵(ロッド/リール/ライン/リーダー/ルアーの5パーツ分。フックとフロートは未提供)。木の3つ目の「スピニング」は、`spinning_rod` / `spinning_reel` / `pe_line` / `fluorocarbon_leader` / `minnow_lure` の5枚:

| ランク | 型A | 型B |
|---|---|---|
| 木 | 入門スピニングセット / スピニング | 振出竿セット |
| 鉄 | バス・スピニング | バス・ベイト |
| ダイヤ | エギング | オフショアジギング |
| ネザライト | GTポッピング | ビッグゲーム |

- アイテムID: `<part>_<type>_<rank>`(例: `rod_blank_beginner_spinning_wood`)。型のIDは英名(`beginner_spinning` / `spinning` / `telescopic` / `bass_spinning` / `bass_bait` / `eging` / `offshore_jigging` / `gt_popping` / `big_game`)。標準型は現行ID(`reel_wood` 等)を維持し、既存のワールドを壊さない
- 型はランク専用(木のパーツには木の3型だけ)。パーツ数: 現行28種 + 型付き(9型 × 7パーツ) = 91種
- 竿のNBT `Tackle` に、ランクと同じ形で型を保存(`reel_type`)。無ければ標準 → 旧竿はそのまま動く
- 型の補正は、そのパーツ自身の主数値と重さにだけ効く(他パーツの数値には波及しない)。`RodSetup` のランク表に対する倍率/加算で表し、既存の数値の範囲内で完結する

## 型の方向性(数値は積載量のバランステストで詰める)
各型は、得意と不得意を1つずつ持つ。ランクの総合的な強さは標準型と同じ。

| 型 | 性格 | 得意 | 不得意 |
|---|---|---|---|
| 木 / 入門スピニング | 扱いやすい万能 | 軽い(重さ -1…標準の重さの範囲で) | 主数値が控えめ |
| 木 / スピニング | 定番のバランス型 | 巻き取りとアタリ | 耐久がやや低い |
| 木 / 振出竿 | 軽量コンパクト | 軽い、アタリが良い | 耐久が低い |
| 鉄 / バス・スピニング | 繊細 | アタリ短縮 | テンションに弱い |
| 鉄 / バス・ベイト | パワー寄りの巻き | 巻き取り | アタリが鈍い、やや重い |
| ダイヤ / エギング | 感度と柔らかさ | 運、アタリ | ダッシュに弱い |
| ダイヤ / オフショアジギング | 大型の突っ込みに耐える | ダッシュ軽減 | 巻き取りが遅い |
| ネザライト / GTポッピング | 強靭な引きに耐える | テンション、ダッシュ | アタリが鈍い、重い |
| ネザライト / ビッグゲーム | 最大パワー | 耐久、積載量 | 巻き取りが遅い、とても重い |

- ロッドの型だけ、積載量にも補正を持てる(例: ビッグゲーム +2、振出竿 -1)。他のパーツは重さの補正のみ
- 補正後の値は既存の上下限(例: テンション倍率の下限)でクランプする

## 積載量(重量)と、高ランクの弱点(2026-11-12 改訂。セットボーナスは作らない)
目的: 「全部ネザライトが最強」をやめ、どのパーツをどのランクにするかを考える楽しみを作る。同じ素材で揃える有利さは付けない。

- 各パーツ(ロッド以外の6つ)に「重さ」を持たせる。重さ = ランク(木1〜ネザライト4)。型で増減(上の「型の方向性」。最小1)
- ロッドは「積載量」を持つ: 木 12 / 鉄 14 / ダイヤ 16 / ネザライト 18
- 付けたパーツの重さの合計が積載量を超えると、超えた分だけ(超過 1 につき)ペナルティ:
  - 巻き取り ×(1 - 5%)、アタリ短縮 -1pt、テンション ×1.02(悪化)
- 超えなければペナルティなし。軽いほど有利にはならない(軽くして得をするのではなく、強いパーツを何に使うかを選ぶ)
- 全部ネザライト(重さ 24)は、ネザライトのロッド(積載量 18)でも超過 6 になり、巻き取り約-30%・アタリ短縮 -6pt・テンション +12% の重いペナルティを受ける
- 例の組み方(積載量 18 のネザライトロッド): 重さ 4 のパーツ3つ + 重さ 2 のパーツ3つ。何を最強にし、何を軽くするかが選択になる
- ランクの混在は不利にならない(ネザライトのロッドに木のラインでも、積載の余裕ができて有利に働く)。ロッドのランクが高いほど積載量も増えるので、ロッドを上げる意味は残る
- 型どうしの相性ボーナスは作らない

### 数値の検証(実装の最初の段階に含める)
- 4^7 通りの全組み合わせを列挙するテストで、「ほかのどの組み方にも全項目で負けない組み方」(パレート最適)が単一の全ネザライトに偏らないことを確認する
- 超過 1 あたりの傾き(5% / 1pt / 2%)は、その結果を見て調整する。たたき台の傾きで全ネザライトが最強になる場合は傾きを大きくする

### 表示
- 整備台の性能欄に「積載 15 / 18」を出し、超過時は赤字でペナルティの中身を出す
- 竿の説明にも、積載量と超過のペナルティを出す
- パーツのツールチップに、重さを出す

## 作り方(レシピ)
- 無形のレシピ: 同じパーツ・同じランクの任意の型 + 型の素材 → その型
- 型の素材: 型A = 金インゴット + レッドストーン、型B = 銅インゴット + ラピスラズリ(型の素材はランクに関係なく共通)
- 素材の個数 = ランク数(木1〜ネザライト4)
- 標準型へ戻すレシピは作らない(型を付け替えるだけならロスなく別の型へ)。標準に戻したい場合は新しく作る

## GUI・表示
- 整備台: スロットの絵・性能欄は合計値のまま。型の名前は性能の数値に反映される。性能欄の下部のパーツ名にも型名を出す
- 竿の説明: 「リール: 高速型の鉄のリール  x1.27」のように、型名と数値を並べる(前回の数値表示を流用)
- パーツのツールチップ: 型名、補正の説明(例: 巻き取り +15% / テンション +5%)

## 実装での決定(2026-11-12)
- 重さの単位は2倍にした: パーツの重さ = ランク×2 + 型の増減、ロッドの積載量 = 木24/鉄28/ダイヤ32/ネザライト36。超過1点あたりのペナルティは半分(巻き取り -2.5%、アタリ短縮 -0.5pt、テンション +1%)で、旧案と同じ効き方
- 型は「主な数値の倍率(power)」と「重さの増減」の2つで表す(`Style`)。得意・不得意の違いは、強さと重さの釣り合いで表現する
  - ロッドの型: 耐久 ×(1 + 3×power)、積載量 ±(2×重さの増減)
  - ルアーの型: 呼ぶ確率 ×(1 + 2×power)
- 型の数値(power / 重さ): 入門スピニング -5% / -1、スピニング +5% / +1、振出竿 -10% / -2、バス・スピニング -4% / -1、バス・ベイト +8% / +2、エギング -4% / -1、オフショアジギング +8% / +2、GTポッピング +4% / +1、ビッグゲーム +10% / +2
- アタリ短縮は、超過のペナルティで0未満にはならない
- 素材: 型ごとの順序で 金インゴット+レッドストーン / 銅インゴット+ラピス / アメジスト+糸(木のスピニングのみ)。個数はランク数
- 検証: `RodSetupTest` に全組み合わせ(ランクのみ4万通り)の「全項目で最強の組み方がない」テストを入れた
