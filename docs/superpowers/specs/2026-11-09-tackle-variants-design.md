# 釣り竿パーツの「型」追加 設計(計画のみ・未実装)

## 目的
既存の7パーツ(ロッド/リール/ライン/フック/フロート/リーダー/ルアー)に、得意・不得意のある「型」を足す。
既存パーツに素材を足して作り、同じランクの強さは変えず、性能の向きだけを変える。

## 決定事項(ユーザー確認済み)
- 増やし方: 今あるパーツを元に、いくつか素材を足して作る
- 性質: 得意/不得意の型(ランクの総合的な強さは同じ)
- 対象: 全7パーツ
- テクスチャ: ユーザーが渡す。無い型は今は作らず、標準型の絵で代用する

## 型の仕組み
- 各パーツに「標準」+ 2つの型(攻め系 / 守り系)。型は4ランク全てに存在する → パーツ 28 → 84 種
- アイテムID: `<part>_<type>_<rank>`。標準型は現行ID(`reel_wood` 等)を維持し、既存のワールドを壊さない
- 竿のNBT `Tackle` に、ランクと同じ形で型を保存(`reel_type`)。無ければ標準 → 旧竿はそのまま動く
- 型ごとの補正は `RodSetup` のランク表に対する倍率/加算で表す。既存の7種の数値(レベル上限・耐久・巻き取り・テンション・運・アタリ短縮・ダッシュ・ルアー率)の範囲内で完結し、新しい仕組みは足さない

## 型ごとの補正(たたき台。数値は調整前提)
| パーツ | 攻め系 | 守り系 |
|---|---|---|
| ロッド | しなやか: 耐久 -30%、テンション倍率 ×0.95 | 頑丈: 耐久 +50%、巻き取り ×0.95 |
| リール | 高速: 巻き取り +15%、テンション ×1.05 | 剛力: 巻き取り -10%、テンション ×0.92 |
| ライン | 細糸: アタリ短縮 +3pt、テンション ×1.08 | 太糸: テンション ×0.92、アタリ短縮 -3pt |
| フック | 小針: アタリ短縮 +5pt、運 -1 | 大物針: 運 +1、ダッシュ ×1.05 |
| フロート | 高感度: アタリ短縮 +4pt、運 -1 | 重厚: アタリ短縮 -3pt、テンション ×0.97 |
| リーダー | 柔軟: ダッシュ軽減 +0.03、テンション ×1.04 | 硬質: ダッシュ軽減 -0.03、テンション ×0.96 |
| ルアー | 本命: 確率 15%、呼べるLv 4/ランク | 万能: 確率 7%、呼べるLv 7/ランク |

- ロッドはレベル上限を型で変えない(ランクで決まる)
- 補正後の値は既存の上下限(例: テンション倍率の下限)でクランプする

## ランクの混在とセットボーナス(2026-11-12 追加)
- ランクの混在: ネザライトのロッドに木のラインを付けても不利にならない。レベル上限はロッドのランク、他の数値は付けたパーツの数値で決まる(現行どおり)。型どうしの相性ボーナスは作らない
- セットボーナス: 同じ素材(ランク)のパーツを揃えると、追加の効果が付く。型は問わない
  - 4パーツ以上が同じランク: 小ボーナス
  - 7パーツ全部が同じランク: 大ボーナス(小ボーナスも重なる)
- ボーナスはランクごとの個性(たたき台):

| ランク | 小(4つ以上) | 大(7つ全部) |
|---|---|---|
| 木 | アタリ短縮 +3pt | アタリ短縮 +3pt、運 +1 |
| 鉄 | 耐久 +10% | 耐久 +10%、テンション ×0.97 |
| ダイヤ | 巻き取り ×1.05 | 巻き取り ×1.05、運 +1、ダッシュ軽減 +0.03 |
| ネザライト | 耐久 +20% | 耐久 +20%、テンション ×0.95、ルアー確率 +5pt |

- 整備台の性能欄と竿の説明に、有効なセットボーナスの名前と中身を表示する
- ボーナスは `RodSetup` の最後に加算する。型の補正と同じ表の延長で、アイテムとNBTは増やさない

## 作り方(レシピ)
- 無形のレシピ: 同じパーツ・同じランクの任意の型 + 型の素材 → その型
- 型の素材: 攻め系 = 金インゴット + レッドストーン、守り系 = 銅インゴット + ラピスラズリ
- 素材の個数 = ランク数(木1〜ネザライト4)
- 標準型へ戻すレシピは作らない(型を付け替えるだけならロスなく別の型へ)。標準に戻したい場合は新しく作る

## GUI・表示
- 整備台: スロットの絵・性能欄は合計値のまま。型の名前は性能の数値に反映される。性能欄の下部のパーツ名にも型名を出す
- 竿の説明: 「リール: 高速型の鉄のリール  x1.27」のように、型名と数値を並べる(前回の数値表示を流用)
- パーツのツールチップ: 型名、補正の説明(例: 巻き取り +15% / テンション +5%)

## アート
- 要るテクスチャ: `<part>_<攻め|守り型ID>_<rank>.png`(14種×4ランク=56枚、32×32)
- 無いものは標準型の絵を `models/item/*.json` から参照して代用(型の差が分かる色味の枠は付けない)
- 絵が届いたら差し替える(モデル参照を切り替えるだけ)

## 実装の段階
1. データ: `Part`/`RodSetup` に型を足し、補正表を `RodSetupTest` で検証(同ランクの総合値のバランステストを含む)
2. アイテム: 型付きのアイテム、レシピ、lang、モデル(代用テクスチャ)を生成するスクリプト
3. 整備台/竿の表示: 型名の表示、NBTの読み書き、分解時の型の復元
4. テクスチャの差し替え(届き次第)
