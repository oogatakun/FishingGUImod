# 竿とパーツ(Tackle)設計

2026-11-07。ユーザーと合意した内容。

## 目的

釣り竿を「パーツで組む」ものにして、釣りの成長要素を広げる。サーバーがすべてを決める。

## 合意事項

- 整備台(専用ブロック)の GUI で、パーツを組んで竿を作る。外して元に戻せる。
- パーツは 7 種類: ロッド、リール、ライン、フロート、リーダー、フック、ルアー。同時にすべて付けられる。
- 各パーツは 4 ランク: 木、鉄、ダイヤ、ネザライト。
- 最低条件: ロッド、ライン、フックが付いていること。無いと竿として完成しない。リール、フロート、リーダー、ルアーは任意。
- バニラの釣り竿は「ゴミしか釣れない」。ゴミとは、釣り用プールのうち minecraft 名前空間のアイテム(魚ではないもの)。
- ルアーは 10% の確率で、特定の魚種を呼ぶ。
- アイテム、GUI の完成度を高くする。粗末なものは作らない。絵は mc-model-kit で作る。

## 段階

- 第 1 弾(今回): 整備台とGUI、組み上げ竿、ロッド・リール・ライン・フックの 4 パーツ(各 4 ランク)。
- 第 2 弾: フロート、リーダー、ルアー(各 4 ランク)。第 1 弾の GUI にスロットは最初から 7 つ用意し、第 2 弾までは「準備中」の見た目にはしない(第 2 弾まで非表示)。

## 性能の割り当て(既存の仕組みに乗せる)

| パーツ | 効果 | ランク 1〜4 |
|---|---|---|
| ロッド | 使える餌/釣れる魚の上限レベル、竿の耐久値 | 上限 5 / 10 / 15 / 20、耐久 128 / 320 / 800 / 2000 |
| リール | 魚の体力を削る速さ(リール速度) | ×1.10 / 1.20 / 1.30 / 1.40 |
| ライン | リール中に溜まるテンションの量 | ×0.94 / 0.88 / 0.82 / 0.76 |
| フック | 上に一段高いレベルの魚が出る確率(運の加算) | +1 / +2 / +3 / +4 |
| フロート(第2弾) | アタリが来るまでの短縮 | 5% / 10% / 15% / 20% |
| リーダー(第2弾) | ダッシュで溜まるテンションの軽減 | ×0.95 / 0.90 / 0.85 / 0.80 |
| ルアー(第2弾) | 10% で、ルアーに設定した魚種を呼ぶ | ランクは呼べる魚のレベルの上限 |

- 釣りレベル・スキル・既存の効果とは掛け算で重ねる。
- 竿の上限レベルは、餌のレベルが竿の上限を超えていたら、釣り始められない(釣りレベル不足と同じ扱い)。

## 竿アイテム

- 完成した竿は専用アイテム 1 種類(`tackle_rod`)。パーツの種類とランクを NBT(`Tackle`)に持つ。
- バニラの FishingRodItem を継承する(キャスト、ウキ、手の動きはバニラのまま)。
- 耐久は NBT から計算し、`getMaxDamage(stack)` で返す。
- ツールチップに、7 つのパーツとランク、効果を表示する。

## 整備台

- ブロック `tackle_bench`。右クリックで GUI(メニュー)が開く。
- スロット 7 つ + 出力スロット 1 つ。各スロットは、そのパーツしか受け付けない。
- 出力スロットには、パーツから組まれた竿のプレビューが出る。取り出すとパーツが消費される。
- 竿を入力スロット(「分解」スロット)に入れると、パーツに戻る。壊れた竿は、残りの耐久を引き継ぐ。
- 組み替えは、竿を取り出す前ならいつでもできる。

## ゴミしか釣れないバニラ

- バニラの竿でも、釣りのファイトは始まる。
- カタログ(プール)から、minecraft 名前空間のアイテムだけを対象にする。

## 見た目

- パーツアイテム: 16×16 の高密度ドット絵。ランクごとに素材の色と形の細部が違う。
- 竿アイテム: 手に持ったときは、バニラの竿のように見える。ランクで色が変わる絵を 4 種類。
- 整備台: 3D ブロックモデル(キット)。
- GUI: 作業台に似た、ただし独自の絵のスロットとパネル。7 つのスロットの背景に、パーツの影絵を表示する。
