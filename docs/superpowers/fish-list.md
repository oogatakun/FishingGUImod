# 追加する魚のリスト(案)

- 日付: 2026-11-03 / 状態: 案(ユーザー確認待ち)
- 方針: 実在の魚を、レベル1〜20に3種ずつ(合計60種)。バニラの魚4種(タラ・サケ・熱帯魚・フグ)はそのまま使い、残り56種をオリジナルのアイテムとして追加する。
- レア度: Lv1〜5 = common、Lv6〜10 = uncommon、Lv11〜15 = rare、Lv16〜20 = epic。
- 経験値の目安: `10 + 6 × (レベル - 1)`(魚ごとに ±2 程度の調整はあとで可)。
- 重量(kg)は範囲。ファイトの重さ補正(0.8〜1.3 倍)の元になる。
- 難易度(体力、ダッシュ、張力の上がり方)は、レベルが上がるほど強くなる傾向で、実装時に案を出す。

## バニラのゴミ・宝物への仮レベル(案)

- ゴミ(革の長靴、骨、棒、糸、水入りビン、皮、腐肉、骨粉、ボウル、釣り竿の壊れかけ): Lv1〜3。
- 宝物: 名札、鞍、エンチャントの本、弓、釣り竿、オウムガイの殻 = Lv6〜12(アイテムごとに設計時に決める)。

## 確認したいこと

- 魚の入れ替えや、追加してほしい魚、いらない魚。
- 重量の桁は、ゲームとして許せるか(ジンベエザメは最大 15 トン)。大きすぎるなら、上限を縮めてもよい。
- 淡水魚と海水魚の区別は、バックログの項目6(場所ごとの魚)で扱う。今回は付けない。
